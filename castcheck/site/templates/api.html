JSON API v1

Plain static files on a CDN — no server, no keys, no rate limit. Access-Control-Allow-Origin: * and Cache-Control: public, max-age=3600, stale-while-revalidate=86400 on everything under /api/. Every response carries schema_version, generated_at, data_through, window, units, method and truth; every result row can be turned into a permanent link.

Endpoints

PathContents
scores/index.json the index of the sharded scores export: the shard of every station, the column list, and which stations, models, variables, windows and leads exist. scores/latest.json serves the same document — before methodology v0.3 it was the whole table in one 21 MB file.

Python

import io, urllib.request, json
import pandas as pd

BASE = "{{ site_url }}/api/v1"

def table(path):
    """Read a compact {columns, rows} endpoint into a DataFrame."""
    with urllib.request.urlopen(f"{BASE}/{path}") as r:
        payload = json.load(r)
    df = pd.DataFrame(payload["rows"], columns=payload["columns"])
    df.attrs.update({k: payload[k] for k in
                     ("generated_at", "data_through", "units", "method", "truth")})
    return df

# the scores table is sharded: one file per station, listed in scores/index.json
scores = table("scores/by-station/ALL.json")
best = (scores.query("window == '90d' and init_hour == 0 and method == 'bilinear' "
                     "and variable == 't2' and lead_day == 1 and n >= 30")
              .sort_values("mae"))
print(best[["model_id", "n", "mae", "mae_ci_low", "mae_ci_high", "bias"]])

# the per-day record for one station (°C): one row per model/init/lead/method/variable/day,
# and four rows a day for the pooled t2 (valid_hour_utc says which instant). One file per station.
errors = pd.read_csv("{{ site_url }}/data/daily_errors/KNYC.csv.gz")

MAE, bias, RMSE and the interval bounds are in °C in the API and the CSVs; the site displays them in °F (multiply a difference by 1.8).

Stability

Paths under /api/v1/ and the permanent links /station/{ICAO}/model/{model_id}/lead/{d}/ are fixed. Columns may be added within v1; a removal or a change of meaning bumps schema_version and appears in the changelog. Numbers change every day as history accumulates — always record generated_at and data_through with anything you quote.
