JSON API v1

Plain static files on a CDN — no server, no keys, no rate limit. Access-Control-Allow-Origin: * and Cache-Control: public, max-age=3600, stale-while-revalidate=86400 on everything under /api/. The per-station bundles are the one exception: they live at /station/{ICAO}/cards.json, outside /api/, and are CORS-open but revalidated on every request rather than cached for an hour. Every score response carries schema_version, generated_at, data_through, window, units, method and truth (status.json is a completeness report and carries its own fields); every result row can be turned into a permanent link.

PathContents
scores/index.json the index of the sharded scores export: the shard of every station, the column list, and which stations, models, variables, windows and leads exist. scores/latest.json serves the same document — before methodology v0.3 it was the whole table in one 21 MB file.

Python

No key, no rate limit on our side. One platform caveat: Cloudflare's edge rejects the default Python-urllib User-Agent everywhere on the internet it fronts (error 1010) — that is not a CastCheck setting and applies to any Cloudflare-served site. requests, browsers, curl and an empty User-Agent all pass; for urllib/pandas, set any User-Agent string, as the examples below do.

import urllib.request, json
import pandas as pd

BASE = "{{ site_url }}/api/v1"
# The CDN in front of the site rejects the default Python user agent, so name your client.
UA = {"User-Agent": "castcheck-example/1.0"}

def read(url):
    with urllib.request.urlopen(urllib.request.Request(url, headers=UA)) as r:
        return json.load(r)

def table(payload, block=None):
    """A compact {columns, rows} document (or one block of it) as a DataFrame."""
    t = payload if block is None else payload[block]
    df = pd.DataFrame(t["rows"], columns=t["columns"])
    df.attrs.update({k: payload[k] for k in
                     ("generated_at", "data_through", "units", "method", "truth")})
    return df

# the scores table is sharded: one bundle per station, listed in scores/index.json.
# Its label columns are dictionary-encoded, so decode them once:
bundle = read("{{ site_url }}/station/ALL/cards.json")
scores = table(bundle, "scores")
for col, values in bundle["scores"].get("dictionaries", {}).items():
    scores[col] = scores[col].map(dict(enumerate(values)))
best = (scores.query("window == '90d' and init_hour == 0 and method == 'bilinear' "
                     "and variable == 't2' and lead_day == 1 and n >= 30")
              .sort_values("mae"))
print(best[["model_id", "n", "mae", "mae_ci_low", "mae_ci_high", "bias"]])

# the per-day record for one station (°C): one row per model/init/lead/method/variable/day,
# and four rows a day for the pooled t2 (valid_hour_utc says which instant). One file per station.
errors = pd.read_csv("{{ site_url }}/data/daily_errors/KNYC.csv.gz", storage_options=UA)

MAE, bias, RMSE and the interval bounds are in °C in the API and the CSVs; the site displays them in °F (multiply a difference by 1.8).

Stability

Paths under /api/v1/, the per-station bundles /station/{ICAO}/cards.json and the permanent links /station/{ICAO}/model/{model_id}/lead/{d}/ are fixed. Columns may be added within v1; a removal or a change of meaning bumps schema_version and appears in the changelog. Numbers change every day as history accumulates — always record generated_at and data_through with anything you quote.
