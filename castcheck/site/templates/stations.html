Stations

Every station is a first-order NWS site that issues a Daily Climate Report (CLI) and reports routine hourly METARs. The stations are not a random sample: all 23 are major city airports chosen because a daily temperature contract settles on them, which biases the set towards the dry south-west and the north-east corridor (methodology §1). The climatological day is local standard time all year, so each station carries a fixed UTC offset and daylight saving is never applied (methodology §2.1).
